# YYT-Store 交互原型

高保真、可点击的产品原型，自包含 HTML（无需联网/依赖），双击即可在浏览器打开，手机浏览器亦可。

原型按 [12 角色体系](../docs/12-角色体系与权限.md) 的「**管理端 vs 执行端**」分界拆成两端：

| 文件 | 端 | 形态 / 角色 | 内容 |
|------|----|------|------|
| [index.html](index.html) | **执行端**（移动 · 店长/加盟商） | 经营 / 动作 | 工作台（**数据成熟度逐层解锁** + **活动/天气客流预警** + 精简 AI 诊断）· 体检（五圈层雷达+六维评分+点位vs经营矩阵）· AI 问数 · 增长行动 |
| [dashboard.html](dashboard.html) | **管理端**（Web · 集团/区域） | 决策 / 督导 | 全盘总览（健康度分布 + 点位vs经营 + 门店明细）· **门店调改决策**（止损/调改/赋能/维持 分桶 + 决策清单）· **拓店 / 加密评估**（候选点位评分 + 加密蚕食评估） |

### 执行端要点（index.html）
- **数据成熟度**：默认仅外部数据；会员/经营数据未接入时显示「上传/录入解锁」+「帮我对接·增值」，健康分标注完整度、经营表现显示「待数据」。顶部「数据接入」切换可演示由外到内逐层解锁。
- **活动/天气监测**：本商场/周边活动预告、天气 → 客流影响预测 → AI 联动建议（纯外部数据、零接入门槛）。

### 管理端要点（dashboard.html）
- 侧边栏切换视图：全盘总览 / 门店调改 / 拓店·加密。
- **门店调改**：按「点位×经营」四象限给出止损/调改/赋能/维持建议与优先级。
- **拓店/加密**：外部数据为候选点位打分，并评估新店对自有门店的蚕食净增益。
